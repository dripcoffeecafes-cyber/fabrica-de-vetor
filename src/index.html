          Como usar

          1. Solte a imagem do cliente (PNG, JPG ou WebP). Dá para soltar várias e baixar todas num .zip.
          2. No Claude, o botão Do Google Drive mostra as imagens do seu Drive: recentes, pastas, compartilhadas ou busca pelo nome. Na primeira vez o Claude pede para liberar o acesso.
          3. Escolha o tipo de arte. Logo serve para a maioria dos casos.
          4. Confira as cores: clique numa amostra para trocar pela cor exata da marca, use × para tirar uma cor que sobrou e o conta-gotas para incluir uma que faltou.
          5. Use Comparar e o zoom para conferir as bordas. O fundo kraft simula o sachê de drip.
          6. Baixe o SVG e abra no Illustrator. Cada cor vem num grupo próprio.

          Ajuste fino

          • Clique numa forma do vetor: dá para virar círculo, elipse ou retângulo perfeito, endireitar retas tortas, trocar a cor ou apagar sujeira. Não usa IA.
          • Revisar com IA compara o original com o vetor e sugere ajustes pontuais (cores, fundo, formas). Você escolhe quais aplicar. Escreva o problema no campo, se quiser, para ela focar nele.
          • Os ajustes continuam valendo se você mexer em suavidade, limpeza ou fundo depois. Dá para desfazer um por um.

          No Illustrator

          • Arquivo > Abrir o SVG (ou o PDF). As formas já vêm editáveis, sem precisar expandir.
          • Os grupos têm o nome da cor (ex.: cor-2_3B2314). Para trocar uma cor, selecione o grupo inteiro.
          • Copiar SVG também funciona: no Illustrator, Ctrl+V costuma colar direto como vetor. Se colar como texto, use o arquivo baixado.

          Para sair melhor

          • Quanto maior e mais nítida a imagem, melhor o vetor. Peça o arquivo original ao cliente sempre que der.
          • Se o cliente mandou PDF, AI, EPS ou SVG, ele pode já ser vetor: no computador, abra no Illustrator antes. PDF também entra aqui: cada página vira uma imagem em alta resolução (até 12 páginas) e é vetorizada.
          • Degradê e sombra viram faixas de cor. Para logo, diminua a quantidade de cores.
          • Branco dentro da arte aparece num grupo próprio. Se o sachê for kraft, apague esse grupo ou mantenha para imprimir com branco.
          • Camadas recortadas servem para plotter de recorte e serigrafia (nada fica sobreposto).
          • Nada sai do seu computador: a imagem é processada aqui no navegador.
